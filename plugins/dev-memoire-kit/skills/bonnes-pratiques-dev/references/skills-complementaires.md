# Skills complémentaires (communauté)

La marketplace `dev-memoire-kit` référence aussi des skills populaires d'autres auteurs, choisis et relus pour des étudiants développeurs. Ils ne sont **pas installés avec ce kit** : chacun s'installe à part, à la demande.

Quand la situation s'y prête et que le skill n'est pas déjà installé, le **proposer en une phrase** avec sa commande, sans insister. Ne jamais l'installer à la place de l'utilisateur.

| Situation de l'utilisateur | Skill à proposer | Commande |
|---|---|---|
| Prépare sa soutenance, veut être interrogé sur son plan ou ses choix techniques | `soutenance-grill-me` (Matt Pocock, MIT) | `/plugin install soutenance-grill-me@dev-memoire-kit` puis `/grill-me` |
| Veut écrire des tests avant le code, parle de TDD | `tdd` (Matt Pocock, MIT) | `/plugin install tdd@dev-memoire-kit` |
| Bloque sur un bug difficile ou une lenteur | `diagnostic-bugs` (Matt Pocock, MIT) | `/plugin install diagnostic-bugs@dev-memoire-kit` |
| Veut améliorer l'architecture d'un projet existant, glossaire, ADR | `architecture-code` (Matt Pocock, MIT) | `/plugin install architecture-code@dev-memoire-kit` |
| Veut apprendre une technologie sur plusieurs séances | `apprendre-une-techno` (Matt Pocock, MIT) | `/plugin install apprendre-une-techno@dev-memoire-kit` puis `/teach` |
| Construit une interface web et veut un rendu soigné | `frontend-design` (Anthropic, Apache-2.0) | `/plugin install frontend-design@dev-memoire-kit` |
| Veut tester son application web dans un navigateur | `tests-webapp` (Anthropic, Apache-2.0) | `/plugin install tests-webapp@dev-memoire-kit` |
| Projet React ou Next.js, questions de performance | `react-bonnes-pratiques` (Vercel, MIT) | `/plugin install react-bonnes-pratiques@dev-memoire-kit` |
| Application mobile React Native ou Expo | `react-native-bonnes-pratiques` (Vercel, MIT) | `/plugin install react-native-bonnes-pratiques@dev-memoire-kit` |
| Veut créer son propre skill ou contribuer au kit | `creer-un-skill` (Anthropic, Apache-2.0) | `/plugin install creer-un-skill@dev-memoire-kit` |

Ces skills sont en anglais ; Claude répond quand même en français.

Chaque entrée est figée sur la version relue (commit précis du dépôt d'origine). Une nouvelle version d'un auteur n'arrive qu'après relecture et mise à jour de la marketplace.
